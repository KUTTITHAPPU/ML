Exploratory Data Analysis (EDA)

An approach to analyzing datasets to summarize main characteristics using graphics and statistics.

4 Main Objectives:

  • Identify patterns, outliers, and missing data.
  • Check statistical assumptions for ML models.
  • Understand feature-target relationships.
  • Guide feature selection & engineering.

Numerical vs. Categorical Variables

Numerical

Measurable numbers where arithmetic operations make sense.

Ex: Age, BMI, Charges
Categorical

Values representing discrete groups or text labels.

Ex: Smoker, Attrition_Flag

Overfitting vs. Underfitting

  • Underfitting (High Bias): Model is too simple; performs poorly on both training and test data.
  • Overfitting (High Variance): Model memorizes training noise; performs exceptionally on training set but poorly on unseen test data.

Univariate vs. Bivariate Analysis

Univariate: Analyzing one feature at a time (e.g., histogram of `charges` or `countplot` of target variable).
Bivariate: Analyzing the relationship between two variables simultaneously (e.g., boxplot of `smoker` vs `charges`).

Classification Evaluation Metrics Explained

Accuracy

Overall correct predictions ratio.

(TP + TN) / Total
Precision

Out of predicted positives, how many are true positive? (Avoids false alarms).

TP / (TP + FP)
Recall (Sensitivity)

Out of actual positives, how many did model catch? (Crucial for Churn & Health).

TP / (TP + FN)
F1-Score

Harmonic mean of Precision and Recall. Best metric for imbalanced data.

2 * (P * R) / (P + R)

Ensemble & Tree Classifiers Summary

Model Notes
Decision Tree

Splits data into branches based on feature conditions to create a tree structure. Easy to interpret but prone to overfitting without pruning.

Pros: No feature scaling required.
Random Forest

An ensemble of multiple decision trees built using bagging (bootstrap aggregation) and random feature selection.

Pros: Greatly reduces overfitting.
Gradient Boosting

Builds trees sequentially, where each new tree works to minimize the residual errors of the previous trees.

Pros: Highest predictive accuracy.

Option 1: Customer Churn Classification Workflow

Complete encoding, stratified split, DT & Random Forest training & evaluation

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import LabelEncoder
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

# a) Load dataset into DataFrame
data = pd.read_csv("Churn Prediction.csv")

# b) Basic Inspection
print("Shape:", data.shape)
print(data.head())
print(data.info())
print(data.describe())

# c) Identify and remove CLIENTNUM column
if 'CLIENTNUM' in data.columns:
    data = data.drop('CLIENTNUM', axis=1)

# d) Encode target variable Attrition_Flag
attrition_map = {'Existing Customer': 0, 'Attrited Customer': 1}
if data['Attrition_Flag'].dtype == 'object':
    data['Attrition_Flag'] = data['Attrition_Flag'].map(attrition_map)

# e) Encode categorical variables (Ordinal mapping + LabelEncoder + get_dummies)
le = LabelEncoder()
if 'Gender' in data.columns:
    data['Gender'] = le.fit_transform(data['Gender'])

# Perform dummy encoding for remaining categorical features
cat_cols = data.select_dtypes(include=['object']).columns
data = pd.get_dummies(data, columns=cat_cols, drop_first=True, dtype=int)

# f) Separate independent features X and target variable y
X = data.drop('Attrition_Flag', axis=1)
y = data['Attrition_Flag']

# g) Split dataset (70% train, 30% test) using stratification
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)

# h) Build models using Random Forest and Decision Tree
dt_model = DecisionTreeClassifier(random_state=42)
rf_model = RandomForestClassifier(random_state=42)

dt_model.fit(X_train, y_train)
rf_model.fit(X_train, y_train)

# i) Generate predictions for test data
y_pred_dt = dt_model.predict(X_test)
y_pred_rf = rf_model.predict(X_test)

# j & k) Evaluate models and display results
def evaluate(y_true, y_pred, name):
    print(f"\n--- {name} Results ---")
    print("Accuracy :", accuracy_score(y_true, y_pred))
    print("Precision:", precision_score(y_true, y_pred, zero_division=0))
    print("Recall   :", recall_score(y_true, y_pred, zero_division=0))
    print("F1-Score :", f1_score(y_true, y_pred, zero_division=0))

evaluate(y_test, y_pred_dt, "Decision Tree Classifier")
evaluate(y_test, y_pred_rf, "Random Forest Classifier")

Option 2: Health Insurance Regression Workflow

Complete encoding, Linear Regression modeling, MSE & R² score evaluation

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# a) Load dataset
df = pd.read_csv("insurance_prediction.csv")

# b) Perform basic inspection
print("Shape:", df.shape)
print(df.head())
print(df.info())
print(df.describe())

# c) Encode categorical variables sex, smoker and region
df = pd.get_dummies(df, columns=['sex', 'smoker', 'region'], drop_first=True, dtype=int)

# d) Separate X and y (target variable = charges)
X = df.drop('charges', axis=1)
y = df['charges']

# e) Split dataset into 70% training and 30% testing
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# f) Build Linear Regression model
regressor = LinearRegression()
regressor.fit(X_train, y_train)

# g) Predict insurance charges for test data
y_pred = regressor.predict(X_test)

# h & i) Evaluate model using MSE and R2 score
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print("\n--- Regression Evaluation ---")
print("Mean Squared Error (MSE):", mse)
print("R² Score:", r2)

# j) Interpretation:
# High R² score indicates model explains substantial variance in charges.
# MSE measures mean quadratic variance between actual & predicted fees.
